# Tiny Blocks

**Tiny Blocks** is a set of small, focused, framework-agnostic PHP libraries. Each one solves a single problem and can
be adopted on its own, without pulling in the rest.

The building blocks cover the parts most applications rewrite from scratch: collections, time, HTTP primitives and
middleware, object mapping, structured logging, identifiers, encoding, arbitrary precision numbers, and value object
contracts. Some go further and implement a known pattern end to end: the tactical building blocks of Domain Driven
Design, and the Transactional Outbox.

The documentation of every library, how the libraries depend on each other, and search across all of them live at
**[tiny-blocks.github.io](https://tiny-blocks.github.io/)**.

To contribute, follow the [contribution guidelines](https://github.com/tiny-blocks/.github/blob/main/CONTRIBUTING.md).
